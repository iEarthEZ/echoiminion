# Echoiminion

A strange creature is out there at nighat. And it may hunt you 😃

## About

**Echoiminion** adds a new hostile mob to minecraft that comes out at night and follows you, looking for a chance to kill **YOU**.

It doesn't just wander around like your average hostile mob. It actively tries to track you down. If you decide to fight back and hit it, it'll explode you to ur death.

## Features
- **Echoi Minion:** A new mob with a darker creeper appearance.
- **Night Spawn:** Appears at night, when awareness is already doing you absolutely no favors.
- **Player Tracking:** Follows the you and attempts to hunt you.
- **Explosive Backlash:** Hit it, and it'll blow up to your death.

## Installation

1. Download the mod(.jar).
2. Install fabric 1.21.11 in ur minecraft launcher.
3. Put the mod .jar file in ur mods folder and run the game!
